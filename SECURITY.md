# Security Policy

## Supported versions

Only the latest published version of `@lemuayala/glass-ui-core` and `@lemuayala/glass-ui-mcp`
receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub Security Advisories](https://github.com/lemuayala/glass-ui/security/advisories/new).
Include the affected package and version, steps to reproduce, and the impact you expect.

You'll get an acknowledgement within a few days. Once a fix is published, the advisory is made public
with credit to you unless you prefer otherwise.

## Supply chain

Packages are published from GitHub Actions with npm Trusted Publishing (OIDC) and provenance, so every
release on npm links back to the exact commit and workflow that built it. No long-lived npm tokens exist.
